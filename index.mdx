aeryk is a from-scratch x86_64 kernel written in C. It boots via the [Limine](https://codeberg.org/Limine/Limine) bootloader, manages physical and virtual memory with copy-on-write fork, schedules processes using a Multi-Level Feedback Queue, and exposes a Linux-compatible syscall ABI that backs a minimal userland with a working shell.

## What's inside

aeryk implements each layer of a real operating system from the ground up. Every subsystem is self-contained and documented here.

<CardGroup cols={3}>
  <Card title="Memory Manager" icon="memory" href="/architecture/memory">
    PMM with refcounting, 4-level paging VMM, slab allocator, and COW fork.
  </Card>
  <Card title="Scheduler" icon="list-check" href="/subsystems/scheduler">
    MLFQ scheduler with priority boost, time quanta, and an idle process.
  </Card>
  <Card title="Process Model" icon="diagram-project" href="/subsystems/process">
    ELF64 loader, fork/exec, per-process page tables, and file descriptors.
  </Card>
  <Card title="Filesystem" icon="folder-tree" href="/subsystems/filesystem">
    CPIO initramfs parsed at boot into an in-memory VFS tree.
  </Card>
  <Card title="Drivers" icon="plug" href="/subsystems/drivers">
    PS/2 keyboard, APIC timer, and serial port for GDB debugging.
  </Card>
  <Card title="Userland" icon="code" href="/userland/overview">

  </Card>

## Quick start

<Steps>
  <Step title="Install dependencies">
    On **macOS**: `brew install make x86_64-elf-gcc qemu xorriso`

    On **Linux (Debian/Ubuntu)**: `sudo apt install build-essential gcc qemu-system-x86 xorriso`
  </Step>
  <Step title="Build the ISO">
    ```bash macOS
    make TOOLCHAIN_PREFIX=x86_64-elf-
    ```
    ```bash Linux
    make
    ```
  </Step>
  <Step title="Boot in QEMU">
    ```bash macOS — UEFI
    make TOOLCHAIN_PREFIX=x86_64-elf- run
    ```
    ```bash Linux — UEFI
    make run
    ```
    The Limine boot menu appears, then the kernel initialises all subsystems and drops into `/bin/sh`.
  </Step>
</Steps>

</Note>
