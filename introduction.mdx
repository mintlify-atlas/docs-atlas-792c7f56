aeryk is a hobby x86_64 operating system kernel written from scratch in C, booted via the [Limine](https://codeberg.org/Limine/Limine) bootloader. Starting from a bare framebuffer and a font renderer, it has grown into a system capable of managing physical and virtual memory, scheduling processes with a Multi-Level Feedback Queue (MLFQ), handling syscalls from Ring 3 userland, loading ELF binaries out of an initramfs, and running a minimal interactive shell — all without relying on any existing OS infrastructure.

## What aeryk can do

aeryk ships a complete path from power-on to a userland prompt:

1. **Limine** loads the kernel ELF, the PSF1 font, and the initramfs CPIO archive.
2. The kernel initialises the GDT, IDT, framebuffer TTY, serial port, PMM, VMM/paging, APIC timer, slab allocator, MLFQ scheduler, keyboard driver, and syscall interface — in that order.
3. The initramfs is mounted as a read-only VFS, exposing `/bin/init`, `/bin/cat`, `/bin/sh`, `/bin/ls`, and several test programs.
4. `/bin/exectest` and `/bin/sh` are spawned as Ring 3 ELF processes; the scheduler takes over and drops you into a `> ` prompt.

From the shell you can run any binary in `/bin/` by name (e.g. `ls`, `cat hello.txt`).

## Current feature status

Every item below is fully implemented and boots on QEMU today:

- ✅ Boot via Limine (UEFI and BIOS)
- ✅ Framebuffer TTY
- ✅ PSF1 font rendering (cp850-8x16)
- ✅ Global Descriptor Table (GDT)
- ✅ Interrupt Descriptor Table (IDT)
- ✅ Physical Memory Manager (PMM)
- ✅ Virtual memory / paging (VMM)
- ✅ APIC and APIC timer
- ✅ PS/2 keyboard driver (wired to `sys_read` on fd 0, blocking, line-buffered)
- ✅ Slab heap allocator (`kmalloc` / `kfree`)
- ✅ MLFQ scheduler with context switching
- ✅ Serial driver (COM1, used for GDB debugging)
- ✅ Syscall interface (`sys_write`, `sys_exit`, `sys_open`, `sys_read`, `sys_close`, `sys_spawn`, `sys_wait`, `fork`, `execve`)
- ✅ Initramfs (CPIO archive loaded by Limine)
- ✅ Virtual File System (VFS)
- ✅ ELF loader (Ring 3 userland processes)
- ✅ libc (`string.c`, `stdio.c`, `unistd.c`, `stdlib.c`)
- ✅ Userland programs: `init`, `cat`, `sh`, `ls`, `forktest`, `exectest`, `crashtest`
